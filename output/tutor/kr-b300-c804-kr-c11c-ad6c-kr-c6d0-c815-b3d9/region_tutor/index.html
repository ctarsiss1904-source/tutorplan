# 원정동 과외에서 숙제 제출 누락을 줄이는 방법 원정동에서 과외를 받는 학생 중에는 숙제 내용을 대부분 완성하고도 제출할 때 일부를 빠뜨리는 경우가 있습니다. 공책에 푼 문제는 남아 있지만 사진이나 파일을 보내지 않거나, 여러 장 중 한 장을 빠뜨리는 식입니다. 이 글은 숙제를 못 하는 문제가 아니라, 완성한 숙제를 제출 직전에 빠뜨리는 행동을 다룹니다. 핵심은 제출 전 확인 단계를 만들고, 실제 누락률이 줄어드는지 기록하는 것입니다. ## 완성한 숙제가 제출에서 빠지는 순간 학생은 숙제를 끝냈다고 생각한 뒤 곧바로 제출합니다. 이때 머릿속에는 전체 숙제를 했다는 기억만 남고, 문제지·노트·파일처럼 제출해야 할 항목을 하나씩 대조하지 않습니다. 그 결과 일부 문제의 풀이 사진이 빠지거나, 앞면만 보내고 뒷면을 보내지 않는 일이 생깁니다. 숙제의 완성도와 제출의 완결성은 다르기 때문에, “다 했다”는 판단만으로는 누락을 발견하기 어렵습니다. ## 직접 원인은 제출 전 확인 단계의 부재 이 행동의 직접 원인은 제출 직전에 목록을 대조하는 과정이 없다는 데 있습니다. 학생은 숙제를 완성한 시점과 제출한 시점을 하나의 과정으로 여기지만, 실제로는 두 단계가 구분되어야 합니다. 확인 단계가 없으면 제출 버튼을 누르기 전에 무엇을 보내야 하는지 다시 살피지 않습니다. 특히 여러 장의 자료를 한 번에 제출할 때 누락 가능성이 커집니다. 문제는 숙제를 하지 않은 것이 아니라, 제출 대상과 실제 전송 내용을 비교하지 않은 것입니다. ## 제출물을 목록으로 대조하기 숙제를 끝낸 뒤 제출해야 할 항목을 짧은 목록으로 만듭니다. 예를 들어 `문제지 1장`, `풀이 노트 3쪽`, `추가 문제 1장`처럼 실제 제출 단위를 적습니다. 제출 직전에는 목록의 항목과 첨부한 자료를 하나씩 맞춥니다. 목록에 있는 항목이 모두 첨부되었는지 확인한 뒤에만 제출합니다. 이 과정은 숙제를 다시 하는 시간이 아니라, 완성한 숙제가 전부 전달되었는지 확인하는 절차입니다. 처음에는 과외 직전에 함께 대조하고, 익숙해지면 학생이 혼자 목록을 만든 뒤 확인하도록 합니다. 중요한 것은 목록을 기억에 의존하지 않고 눈으로 남기는 것입니다. ## 대표 기준은 숙제 제출누락률 변화는 숙제 제출누락률 하나로 판단합니다. 계산은 다음과 같이 합니다. `숙제 제출누락률 = 누락된 제출 항목 수 ÷ 제출해야 할 전체 항목 수 × 100` 예를 들어 제출해야 할 항목이 한 달 동안 20개였고 그중 3개가 빠졌다면 누락률은 15%입니다. 확인 단계를 적용한 뒤 같은 방식으로 다시 계산해 수치가 줄었는지 봅니다. 숙제를 몇 번 했는지보다, 제출해야 할 항목 중 몇 개가 실제로 빠졌는지가 기준입니다. 제출이 완벽했던 날에는 누락 항목을 0으로 기록합니다. ## 다른 숙제에서도 같은 기준이 유지되는지 확인하기 확인 목록을 한 종류의 숙제에만 사용하지 않고, 문제지·노트·파일 제출처럼 형식이 다른 숙제에도 적용합니다. 다만 매번 새로운 기준을 만들지 않고, 제출해야 할 항목을 적고 실제 자료와 대조하는 같은 절차를 유지합니다. 며칠 동안 학생이 도움 없이 목록을 만들고 제출 전 대조를 수행했는데도 누락률이 계속 낮게 유지되는지 확인합니다. 이때 누락률이 다시 높아지면 제출 직전 확인을 생략한 날이 있었는지 기록을 되돌아봅니다. 목표는 확인 절차를 대신 해 주는 것이 아니라, 학생 스스로 제출 누락을 발견하고 줄이는 것입니다.
