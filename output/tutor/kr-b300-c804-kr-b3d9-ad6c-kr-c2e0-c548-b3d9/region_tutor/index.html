동구 신안동과외

이 페이지는 현재 수준에 맞지 않는 교재를 고르는 학생의 교재 선택 행동을 다룬다. 학생은 수업을 시작할 때 교재의 난도만 보고 선택하거나, 교재가 무엇을 위한 자료인지 확인하지 않은 채 문제를 푼다. 그 결과 내용이 지나치게 어렵거나 이미 익힌 문제만 반복되어 학습 과정에서 교재를 다시 바꾸게 된다.

교재를 고르는 순간에 나타나는 행동

신안동 과외에서 학생이 새 교재를 선택할 때 먼저 확인할 것은 현재 수준과 교재의 목적이다. 그러나 실제로는 표지나 주변의 추천만 보고 교재를 정하는 경우가 있다. 진단 문제를 풀어 보지 않고 바로 시작하면 학생은 교재가 어려운 이유를 자신의 실력 부족으로만 판단할 수 있다.

대표적인 장면은 첫 단원에서 문제를 몇 개 푼 뒤 막히는 것이다. 반대로 문제 대부분을 쉽게 풀면서도 새로운 개념이나 훈련 요소가 나타나지 않는다면 교재가 현재 학습 목적에 맞지 않을 가능성이 있다.

난도와 목적을 구분하지 않을 때 선택이 흔들린다

교재 선택이 반복해서 어긋나는 직접 원인은 난도와 목적을 구분하지 않는 데 있다. 개념을 처음 익히는 교재와 문제를 충분히 연습하는 교재는 같은 과목이어도 역할이 다르다. 학생이 이 차이를 확인하지 않으면 어려운 교재를 골라도 학습 목표가 분명해지지 않는다.

이때 학생은 “어려운 교재가 더 좋은 교재”라고 판단하기 쉽다. 하지만 현재 개념이 안정되지 않은 상태에서 높은 난도의 문제만 풀면 풀이보다 해설을 읽는 시간이 길어진다. 반대로 이미 익힌 내용을 반복하면 교재를 끝까지 사용해도 필요한 학습이 충분히 이루어지지 않는다.

선택 전에 주교재의 목적과 난도를 정한다

교재를 고르기 전에는 주교재가 담당할 목적을 하나로 정한다. 개념 이해가 목적이라면 설명과 기본 문제가 충분한지 확인하고, 적용 연습이 목적이라면 배운 개념을 단계적으로 활용하도록 구성되어 있는지 살핀다.

그다음 학생의 현재 수준에 맞는지 짧게 확인한다. 임의로 한 단원을 펼쳐 기본 문제와 응용 문제를 각각 풀어 보게 하고, 막힌 이유가 개념 부족인지 문제 난도 때문인지 구분한다. 이 과정을 거치면 교재의 이름이나 추천보다 실제 학습 적합성을 기준으로 선택할 수 있다.

교재 적합률로 선택 결과를 확인한다

대표 측정값은 교재 적합률이다. 교재 적합률은 미리 정한 학습 목적과 현재 수준에 맞는 교재 선택이 전체 선택 횟수 중 몇 번 이루어졌는지로 기록한다.

예를 들어 세 번의 교재 선택 중 두 번이 학생의 현재 수준과 학습 목적에 맞았다면 교재 적합률은 2/3으로 기록한다. 단순히 교재를 끝까지 풀었는지는 이 측정값에 포함하지 않는다. 선택 당시 목적과 난도를 제대로 확인했는지가 기준이다.

다음 선택에서 같은 기준을 스스로 적용한다

한 번 적합한 교재를 찾았다고 바로 마무리하지 않는다. 다음 교재를 선택할 때 학생이 먼저 목적을 말하고, 자신의 수준에 맞는 근거를 설명하는지 확인한다. 교사가 기준을 알려 주지 않아도 같은 순서로 판단한다면 선택 행동이 바뀐 것이다.

다음 수업에서는 새 교재를 고르기 전에 학생이 목적과 난도를 먼저 적게 한다. 이후 실제 선택과 사전 판단이 일치했는지 비교하고 교재 적합률을 다시 기록한다. 적합률이 높아지면 현재 수준에 맞는 교재를 고르는 행동이 안정되고 있다는 뜻이다.
