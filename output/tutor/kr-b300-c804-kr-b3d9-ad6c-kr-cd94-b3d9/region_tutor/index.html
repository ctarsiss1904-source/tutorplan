추동과외

대전 동구 추동에서 동명초등학교에 다니는 학생이 과외를 시작하기 전 자료를 찾으려 한다. 교재와 프린트를 받은 순서대로 쌓아 둔 탓에 필요한 자료가 어디 있는지 바로 판단하지 못하고, 여러 장을 넘긴 뒤에야 찾는다. 이 글은 자료를 목적별로 찾는 과정에서 탐색시간이 길어지는 한 가지 행동을 살펴보고, 자료 위치를 고정해 찾는 시간을 줄이는 방법을 다룬다.

필요한 자료를 찾기 전 이미 시간이 길어지는 장면

학생은 과외를 시작하기 전에 책상 위 자료를 한꺼번에 펼친다. 현재 배우는 내용인지, 다시 확인할 자료인지, 시험에 사용할 자료인지 구분하지 않은 채 받은 순서대로 종이를 넘긴다. 자료의 제목을 확인하기보다 기억에 의존해 찾기 때문에 첫 장부터 필요한 자료가 나와도 지나칠 수 있다.

이때 확인할 행동은 자료를 찾는 데 걸린 시간이다. 필요한 자료를 찾기 시작한 순간부터 실제 자료를 손에 들기까지의 시간을 기록한다. 자료를 찾는 동안 같은 묶음을 다시 확인하거나 다른 자료 더미로 이동한 횟수는 탐색시간이 길어진 과정을 설명하는 보조 기록으로만 남긴다.

받은 순서대로 쌓아 두면 찾는 순간 판단이 멈춘다

자료가 쌓인 순서와 자료를 다시 사용할 목적은 서로 다르다. 학생은 종이를 받은 순서는 기억해도, 어느 자료가 현재 학습에 필요한지까지 즉시 떠올리지는 못한다. 그래서 자료를 찾을 때마다 한 장씩 내용을 확인해야 하고, 찾는 과정이 길어진다.

문제는 자료가 부족해서가 아니라 위치를 정하는 기준이 없다는 데 있다. 자료를 받은 뒤 바로 둘 곳을 결정하지 않으면 책상 위에 새로운 자료가 놓일 때마다 기존 자료의 위치가 흐려진다. 결국 학생은 자료를 찾는 행동보다 자료를 분류하는 판단에 더 많은 시간을 쓴다.

목적별 세 구역으로 자료 위치를 고정하기

자료를 정리할 때는 먼저 세 구역의 이름을 정한다. 현재 배우는 자료, 다시 확인할 자료, 시험에 사용할 자료로 나누고, 각각의 자료를 해당 구역에만 둔다. 중요한 점은 자료의 종류가 아니라 사용 목적을 기준으로 위치를 정하는 것이다.

처음에는 자료 한 장을 들 때마다 “지금 바로 쓰는가, 다시 확인할 것인가, 시험에 쓸 것인가”를 묻는다. 판단이 끝나면 정한 구역에 넣고, 책상 위에 임시로 남겨 두지 않는다. 구역 안에서도 자료를 세로로 세우거나 얇은 파일에 넣어 표지가 보이게 하면 찾을 때 처음부터 다시 넘기지 않아도 된다.

이 방법은 자료를 예쁘게 정리하는 절차가 아니다. 필요한 자료가 어느 구역에 있는지 먼저 결정해 탐색 범위를 줄이는 절차다. 자료를 찾기 전에 구역을 떠올리고, 해당 구역 안에서만 찾도록 하는 것이 핵심이다.

자료 탐색시간으로 변화 확인하기

정리 전에는 자료를 찾기 시작한 시각과 손에 든 시각을 기록한다. 예를 들어 자료를 찾기 시작한 뒤 4분이 지나서야 필요한 프린트를 찾았다면 자료 탐색시간은 4분이다. 정리 후에도 같은 방식으로 기록해야 두 상태를 비교할 수 있다.

자료의 양이나 과외 내용이 달라지면 단순히 시간이 줄었는지만 보지 않는다. 비슷한 양의 자료를 찾게 한 뒤 탐색시간을 비교한다. 목표는 자료를 찾을 때마다 정해 둔 구역으로 바로 이동하고, 그 안에서 짧은 시간 안에 필요한 자료를 꺼내는 것이다.

다른 자료 묶음에서도 같은 기준이 남는지 확인하기

한 번 정리한 자료에서 탐색시간이 줄었다고 바로 끝내지 않는다. 새로 받은 프린트나 다른 교재를 같은 세 구역에 넣은 뒤 다시 필요한 자료를 찾는다. 새로운 자료에서도 구역을 바로 선택하고 탐색시간이 짧게 유지되는지 확인한다.

학생이 도움 없이 자료를 분류하고 찾을 수 있다면 정리 기준이 행동으로 자리 잡은 것이다. 반대로 다시 받은 순서대로 쌓거나 모든 자료를 한곳에 모으면 원래 문제가 반복된다. 이때는 구역 수를 늘리지 말고, 세 구역의 이름과 위치를 다시 고정한다.
