처음부터 읽기 시작하는 손의 움직임에서 확인할 것

필요한 한 줄을 찾는 장면에서는 학생이 몇 줄을 읽었는가보다 어디에서 읽기를 시작했는가가 중요합니다. 페이지를 다시 열자마자 첫 줄로 돌아가는지, 이전에 표시해 둔 위치를 먼저 찾는지 관찰해야 합니다. 현재 기록에 별도 표시가 없다면 학생은 매번 같은 출발점으로 돌아갈 수밖에 없습니다. 기록의 내용이 충분한데도 찾는 데 오래 걸리는 이유는 정보가 없어서가 아니라 핵심 기록과 과정 기록이 한 페이지 안에서 같은 방식으로 보이기 때문입니다.

표시할 줄을 고르는 순간에는 새로운 정리 방법을 여러 개 추가하지 않습니다. 색을 여러 종류로 나누거나, 별도의 목록을 만들거나, 페이지 전체를 다시 편집하게 하지 않습니다. 한두 줄이라는 범위 안에서 다음에 다시 볼 내용을 학생이 직접 선택하도록 하고, 나머지 과정 기록은 현재 형태로 둡니다. 이 제한이 있어야 변화의 원인이 표시 하나인지 분명해집니다. 표시가 생겼다는 사실보다, 학생이 다음 확인을 위해 어떤 문장을 핵심으로 판단했는지가 중요합니다.
